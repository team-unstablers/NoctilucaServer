# i18n Skill

UI 코드에서 하드코딩된 문자열을 `String(localized:defaultValue:)`로 변환하는 스킬입니다.

## Usage

```
/i18n [파일 경로 또는 디렉토리]
```

## Instructions

이 스킬이 호출되면 다음 단계를 수행하세요:

### 1. 대상 파일 탐색

- 인자로 파일 경로가 주어지면 해당 파일만 처리
- 인자로 디렉토리가 주어지면 해당 디렉토리 내 모든 Swift 파일 처리
- 인자가 없으면 현재 프로젝트의 UI 디렉토리를 탐색
  - NoctilucaServer: `NoctilucaServer/ui/`
  - NoctilucaClient: `NoctilucaClient/core/ui/`, `NoctilucaClient/app/macos/ui/`, `NoctilucaClient/app/ios/ui/`
- 기존 `Localizable.xcstrings` 파일이 있으면 그 안의 키들을 먼저 확인하여 중복을 방지

### 2. 하드코딩된 문자열 식별

다음 패턴의 하드코딩된 한글/영문 문자열을 찾습니다:

- SwiftUI `Text("...")` 내부 문자열
- `Label("...", systemImage:)` 첫 번째 인자
- `.navigationTitle("...")`
- `.alert("...", ...)` 제목
- `.confirmationDialog("...", ...)` 제목
- `Button("...") { ... }` 레이블
- `Section("...")` 헤더
- `.help("...")`
- `.accessibilityLabel("...")`
- `.placeholder("...")`
- 기타 UI에 표시되는 문자열 리터럴

### 3. 키 네이밍 규칙

키는 다음 도메인별 규칙을 따릅니다:

```
<domain>.<context>.<item>[.<subitem>][.<variant>]
```

#### 도메인별 패턴

| 도메인 | 패턴 | 예시 |
|--------|------|------|
| 설정 (앱) | `settings.<tab>.<section>.<item>[.<variant>]` | `settings.general.title`, `settings.projection.audio.enable` |
| 세션 설정 | `session-settings.<tab>.<section>.<item>` | `session-settings.projection.codec.title` |
| 메뉴 | `menu.<context>.<action>` | `menu.server.start`, `menu.settings` |
| 알림 | `notification.<event>.<part>` | `notification.new_connection.title` |
| 인증 | `auth.<context>.<item>` | `auth.challenge.password_label`, `auth.identity.warning` |
| 연락처 | `contacts.<context>.<item>` | `contacts.add.title`, `contacts.item.delete` |
| 메인 화면 | `main.<context>.<item>` | `main.address_bar.placeholder`, `main.new_connection.title` |
| About | `about.<item>` | `about.version`, `about.oss_license` |
| 코어/에러 | `core.<module>.<error>.<variant>` | `core.plugin.PluginBundleRegistryError.invalidBundle` |
| 플러그인 | `plugins.<type>.<id>.<part>` | `plugins.auth.SimplePasswordAuthPlugin.name` |
| 온보딩 | `onboarding.<step>.<part>` | `onboarding.completion.title` |
| 공통 | `common.<action>` | `common.cancel`, `common.save`, `common.delete` |

#### 공통 버튼/액션은 `common.*` 사용

자주 반복되는 버튼 레이블은 도메인마다 키를 만들지 말고, `common.*` 키를 공유합니다:
- `common.cancel` → "취소"
- `common.save` → "저장"
- `common.delete` → "삭제"
- `common.confirm` → "확인"
- `common.add` → "추가"
- `common.connect` → "연결하기"
- `common.reset_to_default` → "기본값으로 복원"

### 4. 변환 수행

#### 기본 패턴: `String(localized:defaultValue:)`

```swift
// Before
Text("일반")
Button("저장") { ... }
.navigationTitle("설정")
Section("비디오 코덱") { ... }

// After
Text(String(localized: "settings.general.title", defaultValue: "일반"))
Button(String(localized: "common.save", defaultValue: "저장")) { ... }
.navigationTitle(String(localized: "settings.title", defaultValue: "설정"))
Section(String(localized: "settings.projection.video_codec.header", defaultValue: "비디오 코덱")) { ... }
```

#### 동적 값이 포함된 문자열: `String(format:)`

문자열 보간(`\(variable)`)이 포함된 경우 `%@`, `%d` 등의 포맷 지정자를 사용합니다:

```swift
// Before
Text("버전 \(NoctilucaMeta.version)")
Text("\(hostname)에서 인증서를 제시했습니다.")

// After
Text(String(format: String(localized: "about.version_format", defaultValue: "버전 %@"), NoctilucaMeta.version))
Text(String(format: String(localized: "auth.identity.cert_presented_format", defaultValue: "%@에서 인증서를 제시했습니다."), hostname))
```

#### 마크다운이 포함된 문자열: `Text(markdown:)`

프로젝트에 `Text(markdown:)` 익스텐션이 있는 경우, 마크다운 문법이 포함된 로컬라이즈 문자열에 사용합니다:

```swift
// Before
Text("저희 [주식회사 팀언스테이블러즈](https://unstabler.pl)에게 일을 맡겨주세요")

// After
Text(markdown: String(localized: "about.appeal.body", defaultValue: "저희 [주식회사 팀언스테이블러즈](https://unstabler.pl)에게 일을 맡겨주세요"))
```

`Text(markdown:)` 익스텐션이 없는 프로젝트에서는 직접 추가하세요:

```swift
extension Text {
    init(markdown: String) {
        self.init(LocalizedStringKey(markdown))
    }
}
```

#### static 컨텍스트: `NSLocalizedString`

`static let` 등 Swift의 `String(localized:)`를 사용할 수 없는 정적 컨텍스트에서는 `NSLocalizedString`을 사용합니다:

```swift
// Before
static let metadata = PluginMetadata(
    displayName: "기본 인증 플러그인",
    description: "비밀번호 인증을 제공합니다."
)

// After
static let metadata = PluginMetadata(
    displayName: NSLocalizedString("plugins.auth.SimplePasswordAuthPlugin.name", comment: "SimplePasswordAuthPlugin"),
    description: NSLocalizedString("plugins.auth.SimplePasswordAuthPlugin.description", comment: "Provides password-only authentication")
)
```

> **참고:** `NSLocalizedString`의 `comment`에는 번역가를 위한 영문 설명을 넣습니다.

### 5. 변환 제외 대상

다음은 변환하지 않습니다:

- 이미 `String(localized:)`, `NSLocalizedString`, `LocalizedStringKey`로 감싸진 문자열
- `systemImage:`, `systemName:` 등 SF Symbol 이름
- 디버그/로그 메시지 (`print`, `logger`, `debugPrint`, `os_log` 등)
- 주석 내 문자열
- 파일 경로, URL 문자열
- 코드 내부 식별자 (enum case, dictionary key, UserDefaults key 등)
- 기술 식별자 및 고유명사 (`"HIDIO"`, `"GameController.framework"`, `"QUIC"`, `"H.264"`, `"Opus"` 등)
- 앱 이름 (`"Noctiluca"`, `"Noctiluca Navigator"`) — 단, UI에 표시되는 앱 설명은 변환
- Copyright 문자열 (`"Copyright © ..."`)
- `String(format:)` 내의 포맷 문자열이 이미 로컬라이즈된 경우
- `#selector`, `@objc` 관련 문자열

### 6. 작업 완료 후

- 변환한 파일 목록과 변경 내용 요약을 보고
- 새로 추가한 키의 개수와 주요 키 목록을 보고
- `common.*` 키로 통합한 중복 문자열이 있으면 언급

## Example

```
/i18n NoctilucaClient/NoctilucaClient/core/ui/settings/GeneralSettingsTab.swift
```

→ 해당 파일의 하드코딩된 문자열을 모두 `String(localized:defaultValue:)` 형태로 변환합니다.

```
/i18n NoctilucaClient/NoctilucaClient/core/ui/auth/
```

→ auth 디렉토리 내 모든 Swift 파일의 하드코딩된 문자열을 변환합니다.
