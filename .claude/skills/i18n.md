# i18n Skill

UI 코드에서 하드코딩된 문자열을 `String(localized:defaultValue:)`로 변환하는 스킬입니다.

## Usage

```
/i18n [파일 경로 또는 디렉토리]
```

## Instructions

이 스킬이 호출되면 다음 단계를 수행하세요:

### 1. 대상 파일 탐색

- 인자로 파일 경로가 주어지면 해당 파일만 처리
- 인자로 디렉토리가 주어지면 해당 디렉토리 내 모든 Swift 파일 처리
- 인자가 없으면 `ui/` 디렉토리 내 모든 Swift 파일 처리

### 2. 하드코딩된 문자열 식별

다음 패턴의 하드코딩된 한글/영문 문자열을 찾습니다:

- SwiftUI `Text("...")` 내부 문자열
- `Label("...", systemImage:)` 첫 번째 인자
- `.navigationTitle("...")`
- `.alert("...", ...)` 제목
- `.confirmationDialog("...", ...)` 제목
- `Button("...") { ... }` 레이블
- `.help("...")`
- `.accessibilityLabel("...")`
- 기타 UI에 표시되는 문자열 리터럴

### 3. 키 네이밍 규칙

키는 다음 규칙을 따릅니다:

```
[화면/컴포넌트].[섹션].[요소].[속성]
```

예시:
- `settings.general.title` → "일반"
- `settings.general.autostart.title` → "앱 기동 시 서버 자동으로 시작"
- `settings.general.autostart.description` → 설명 텍스트
- `menu.server.start` → "서버 시작"
- `menu.server.stop` → "서버 중지"
- `alert.error.title` → "오류"
- `button.save` → "저장"
- `button.cancel` → "취소"

### 4. 변환 수행

하드코딩된 문자열을 발견하면:

**Before:**
```swift
Text("일반")
Button("저장") { ... }
.navigationTitle("설정")
```

**After:**
```swift
Text(String(localized: "settings.general.title", defaultValue: "일반"))
Button(String(localized: "button.save", defaultValue: "저장")) { ... }
.navigationTitle(String(localized: "settings.title", defaultValue: "설정"))
```

### 5. 변환 제외 대상

다음은 변환하지 않습니다:

- 이미 `t(...)`, `String(localized:)`, `NSLocalizedString`으로 감싸진 문자열
- `systemImage:`, `systemName:` 등 SF Symbol 이름
- 디버그/로그 메시지 (print, logger, debugPrint 등)
- 주석 내 문자열
- 파일 경로, URL 문자열
- 코드 내부 식별자 (enum case, key 등)

### 6. 작업 완료 후

- 변환한 파일 목록과 변경 내용 요약을 보고

## Example

```
/i18n ui/views/settings/GeneralSettingsTab.swift
```

→ 해당 파일의 하드코딩된 문자열을 모두 `String(localized:defaultValue:)` 형태로 변환합니다.
