Noctiluca Navigator 0.9.2

이번 업데이트는 프로젝션 성능 개선, 화질 설정 확장, HiDPI 지원 및 다수의 안정성 향상을 포함합니다.

1. 프로젝션 성능 향상
- 타일 코덱(WebP, ZRLE, MJPG) 사용 시 Metal 기반 직접 렌더링으로 전환하였습니다. 기존 AVSampleBufferDisplayLayer 경유 경로 대비 불필요한 픽셀 버퍼 복사가 제거되어 렌더링이 더 빨라졌습니다.
- 타일 디코딩을 병렬로 처리하도록 변경하여, 멀티코어 환경에서의 디코딩 속도가 향상되었습니다.

2. HiDPI 디스플레이 지원
- 서버의 Retina(HiDPI) 디스플레이를 원본 해상도로 전송받을 수 있게 되었습니다.
- HiDPI 프로젝션 시 원격 커서가 작게 나오던 문제를 수정하였습니다.

3. 화질 설정 확장
- 코덱 설정 시트가 '기본'과 '고급' 탭으로 분리되었습니다.
- 품질 정책을 선택할 수 있게 되었습니다: 자동, VBR(가변 비트레이트), CBR(고정 비트레이트), 무손실 중 선택이 가능합니다.
- 비트레이트를 직접 조절할 수 있습니다. 품질 정책에 따라 최대 비트레이트 또는 목표 비트레이트를 설정합니다.
- 최대 해상도를 제한할 수 있게 되었습니다(480p~4K 또는 무제한).
- Opus 오디오 코덱 설정 시트가 추가되었습니다.

4. 커서 크기 배율 설정
- 원격 커서의 표시 크기를 0.5x~1.5x 범위에서 조절할 수 있는 설정이 추가되었습니다.

5. 프로젝션 세션 자동 재시작
- 프로젝션 세션이 예기치 않게 종료되었을 때 자동으로 재연결을 시도합니다(최대 3회).

6. 입력 설정 수정
- 마우스 버튼 반전, 스크롤 반전 및 스크롤 배율 설정이 변경 후 즉시 반영되지 않던 문제를 수정하였습니다.
- Exclusive 모드 진입 시 마우스 커서가 숨겨지지 않던 문제를 수정하였습니다.

7. 연결 안정성 개선
- 서버 응답이 연속 3회 실패하면 연결이 끊어진 것으로 판단하도록 변경하였습니다. 일시적인 지연으로 인한 불필요한 연결 해제가 줄어듭니다.

8. UI 개선
- macOS: 성능 오버레이를 드래그할 때 떨리던 현상을 수정하였습니다.
- macOS: 시트 배경(dimming window)에 둥근 모서리가 적용되었습니다.
- macOS: 메인 윈도우의 최소 크기가 보장됩니다. 더 이상 창을 과도하게 작게 줄일 수 없습니다.
- iOS: 프로젝션 화면의 배경이 파란색으로 나오던 문제를 수정하였습니다.
- iOS: 설정 화면의 각 섹션 버튼이 파란색으로 나오던 문제를 수정하였습니다.
- iOS: iPad 멀티태스킹(슬라이드 오버 등) 시 화면이 깜빡이던 문제를 수정하였습니다.
- iOS: 플로팅 팔레트 등의 떠 있는 오버레이가 부모 뷰 영역 밖에서도 올바르게 표시됩니다.

9. 보안 강화
- 인증 시 입력된 비밀번호 등의 민감 정보가 전송 후 메모리에서 즉시 삭제되도록 개선하였습니다.

10. 다국어 지원 확대
- 다수의 하드코딩된 한국어 문자열이 다국어 키로 전환되었습니다.
- 인증서 경고 문구, 일본어 조사 오류 등 번역이 교정되었습니다.
- 비밀번호 입력 필드에 포커스 시 CJK 입력기가 자동으로 ABC 자판으로 전환됩니다.
