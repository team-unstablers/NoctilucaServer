Noctiluca Navigator 0.9.1 (빌드 4)

이번 업데이트는 iOS / iPadOS에서의 사용성 개선을 목표로 하였습니다.
아래 기능이 추가 / 개선되었습니다:

1. '플로팅 팔레트' 추가
- 프로젝션 화면에 떠 있는 반투명 버튼이 새로 생겼습니다. 탭하면 메뉴가 펼쳐집니다.
- 소프트웨어 키보드 토글, 줌 모드 전환을 팔레트에서 바로 할 수 있습니다.
- 드래그로 원하는 위치에 이동할 수 있으며, 놓으면 화면 가장자리로 자동 스냅됩니다.

2. 프로젝션 화면 줌 기능
- 핀치 제스처로 원격 화면을 최대 5배까지 확대할 수 있습니다.
- 커서 추적 줌: 서버의 마우스 커서를 따라 화면이 자동으로 이동합니다.
- 프리 줌: 세 손가락 드래그로 확대된 화면을 직접 이동할 수 있습니다.

3. 키보드 보조 바 개선
- iPad: Esc, Tab, Delete + 수정키(Control, Option, Command, Shift) + 방향키 십자 패드를 제공합니다.
- iPhone: 방향키 + 수정키의 컴팩트 레이아웃
- 키 반복이 가능해졌습니다: 키를 계속 누르고 있으면 반복 전송이 이루어집니다.

4. 기타 개선 사항
- '잃어버린 10픽셀'을 찾았습니다: SwiftUI 기반의 어드레스 바를 부분적으로 UIKit으로 이행하며 돌려받았습니다.
- 앱이 백그라운드로 전환될 때의 프로젝션 세션 처리가 안정화되었습니다. 앱을 전환하거나 슬립 모드에 다녀왔을 때 화면이 검게 변하던 문제를 수정하였습니다.
