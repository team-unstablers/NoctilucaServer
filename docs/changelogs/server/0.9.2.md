## Noctiluca Server 0.9.2

이번 업데이트는 화질 설정 확장, HiDPI 지원, 인증서 관리 개선 및 다수의 안정성 향상을 포함합니다.

### 중요 안내

> **중요 #1**
> 실수로 제 손으로 배포용 인증서의 키를 삭제해 버려 재발급을 받게 되었습니다. (**서명 정보가 바뀌어 버렸습니다!**)
> 따라서, **이번 버전 설치 후에는 반드시 시스템 설정 -> 개인정보 보호 및 보안 탭에서 각 권한에서 'NoctilucaServer' 앱을 수동으로 제거 후 다시 등록해 주셔야 합니다.** (껐다 켜는 것으로는 부족할 것입니다)
> 양해 바랍니다.

> **중요 #2**
> 이번 버전에서는 일시적으로 macOS의 최소 요구 버전이 15 (Sequoia)로 상향되었습니다.
> UI 관련 사항과 테스트 환경이 정비되는 대로 macOS 14 (Sonoma)로 다시 요구 버전을 내릴 예정입니다.

### 개선 사항

1. 화질 설정 확장
- 코덱 설정 시트가 '기본'과 '고급' 탭으로 분리되었습니다.
- 품질 정책을 선택할 수 있게 되었습니다: 자동 조정, VBR(가변 비트레이트), CBR(고정 비트레이트), 고정 품질, 무손실 중 선택이 가능합니다.
- 품질 정책에 따라 비트레이트 또는 품질 팩터를 직접 조절할 수 있습니다.
- Opus 오디오 코덱의 비트레이트(32~256kbps)를 조정할 수 있게 되었습니다. (아직 비트레이트 협상은 지원하지 않습니다)
- 코덱 협상 시 클라이언트의 선호 옵션이 더 잘 반영되도록 개선되었습니다.

2. HiDPI 디스플레이 지원
- Retina(HiDPI) 디스플레이를 원본 해상도로 전송할 수 있게 되었습니다. 디스플레이 밀도 설정을 "화질 우선"으로 변경하면 네이티브 해상도(2x)로 전송됩니다.
- 클라이언트가 최대 해상도를 제한한 경우, 서버가 해당 해상도에 맞춰 화면을 축소하여 전송합니다. 원본 종횡비는 유지됩니다.
- 디스플레이 해상도 계산이 정확해졌습니다. 일부 Retina 디스플레이에서 해상도가 잘못 결정되던 문제가 수정되었습니다.

3. 인증서 관리 개선
- 서버 시작 시 인증서 문제가 발생하면, 원인에 맞는 에러 메시지와 복구 옵션이 다이얼로그로 표시됩니다. "자가 서명 인증서 자동 구성" 버튼으로 즉시 복구할 수 있습니다.
- 키체인에 동일한 이름의 서버 인증서가 여러 개 존재하는 경우 이를 감지하여 명확한 안내를 제공하고, 자가 서명 인증서 재생성 시 기존 중복 인증서를 모두 정리합니다.
- Keychain으로부터 인증서를 선택 시, 대한민국 정부에서 개인 인증 / 전자 서명 용도로 발급한 공인인증서가 후보군으로 표시되던 문제를 수정하였습니다.
- 자가 서명 인증서를 재발급 시도 시, 이따금 무관한 항목이 제거될 수 있는 버그를 수정하였습니다.

4. 입력(HIDIO) 개선
- Ctrl+방향키로 macOS 가상 데스크톱(Spaces) 전환이 가능해졌습니다.
- Alt+F2 등 펑션 키 기반 시스템 단축키(Spotlight 검색 등)가 정상 동작합니다.
- 한/영 키(KEY_HANGEUL)를 눌러 macOS 호스트의 입력 소스를 전환할 수 있게 되었습니다.

5. 프로젝션 안정성 개선
- 프로젝션 세션 중 오류가 발생해도 서버가 크래시하지 않고, 클라이언트에게 실패 사유를 알려주도록 개선되었습니다.
- 프로젝션 세션의 종료/실패 사유가 구조화되어, 클라이언트가 더 정확한 원인을 표시할 수 있게 되었습니다.
- Apple 내장 디스플레이 등 커스텀 색상 프로파일을 사용하는 모니터에서도 색 공간(color gamut)을 판별할 수 있도록 하였습니다. 이는 비-macOS에서의 원격 접속 시 정확한 색상 표시를 위해 필요합니다.

6. 보안 강화
- 인증 과정에서 사용된 비밀번호 등 민감 정보가 전송 후 메모리에서 즉시 삭제되도록 개선되었습니다.
- 최대 동시 접속 수를 설정에서 지정할 수 있으며, 초과 접속이 실제로 차단됩니다.

7. UI 개선
- 설정 윈도우가 macOS 시스템 설정과 유사한 사이드바 네비게이션 형태로 변경되었습니다. 각 항목에 아이콘이 표시됩니다.
- 트레이 메뉴에 "Noctiluca Server에 대하여" 항목이 추가되었습니다. 앱 버전, 오픈소스 라이선스, 사용권 계약 등을 확인할 수 있습니다.
- 이제 텍스트 입력 필드에서 Cmd+C, Cmd+V, Cmd+A 등 표준 편집 단축키가 동작합니다.
- 플러그인 번들의 상세 정보(이름, 개발자, 라이선스, 제공 기능 목록, 코드 서명 상태)를 확인할 수 있는 시트가 추가되었습니다.
- 온보딩 과정에서 뒤로 가기 후 "다음" 버튼 상태가 잘못 표시되던 문제를 수정하였습니다.
- 비밀번호 입력 필드에 포커스 시 CJK 입력기가 자동으로 영문 자판으로 전환됩니다.

10. 연결 안정성 개선
- 빠른 네트워크 환경에서 간헐적으로 클라이언트 연결이 실패하던 레이스 컨디션을 수정하였습니다.
- 스트림 오류 발생 시 에러 원인이 세분화되어 문제 추적이 용이해졌습니다.
